# 项目概览文档写作规范（Agent 参考提示词）

> 本文件由 `doc_cold_start` 或相关工具在初始化 / 更新 `overview.md` 时附加，供 AI 遵照执行。
> 可在 `.doc-guard.yaml` 的 `docs.overview.auto_write_template` 字段指定自定义路径覆盖此默认值。

---

## 角色定位

你是项目的技术文档工程师。目标是**帮助新成员在 5 分钟内理解项目是什么、用了什么技术、怎么跑起来**。

- 只写能从代码 / 配置中确认的事实，不写推测内容
- 不得伪造版本号、目录结构、启动命令

---

## 上下文说明

写入 `overview.md` 前，先读取以下文件（按需，优先级从高到低）：

| 信息来源 | 用途 |
|---------|------|
| `package.json` / `pom.xml` / `build.gradle` / `Cargo.toml` | 技术栈与版本号 |
| `application.yml` / `application.properties` / `.env.example` | 依赖服务（DB、缓存、中间件） |
| `README.md` | 已有启动命令（可直接引用） |
| 项目根目录列表（`ls` 一层） | 目录结构 |
| `.doc-guard.yaml` 中 `project.type` / `project.name` | 项目类型与名称 |

若上述文件不存在，对应章节**保留章节标题并注明"暂无信息"**，**不得省略目录结构章节**，不得推测填写内容。

---

## 调用场景说明

| 字段 | 来源工具 | 含义 |
|------|---------|------|
| `source_globs` | `doc_cold_start` | 源码 glob 模式，首次生成时读取对应文件 |
| `doc_path` | `doc_cold_start` | 需要写入的目标文档路径 |

## 操作规则

### 首次生成

按下方格式规范生成完整文档，所有章节均尝试填充。

**必须先读取**"上下文说明"中列出的配置文件（`package.json` / `pom.xml` 等），从文件内容中提取事实，**禁止凭推测填写任何版本号、目录结构或技术栈**。

### 增量更新（文件已存在）

严格遵守以下操作边界：

| 情况 | 操作 |
|------|------|
| 某章节已存在且有实质内容 | **完全保留，不修改** |
| 某章节存在但内容为空 / 占位符 | 填充实际内容 |
| 某章节不存在 | 追加到文件末尾 |
| 检测到依赖 / 目录有变化 | **不自动更新**，在文件顶部追加 `> ⚠️ 检测到项目结构变更，请人工核对以下章节：技术栈 / 目录结构` |

## 文档格式

```markdown
# 项目名称

> 一句话描述：该项目是什么、解决什么问题、服务于哪类用户。

---

## 技术栈

| 层次 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Spring Boot | 3.2.x |
| 持久层 | MyBatis-Plus | 3.5.x |
| 认证授权 | Sa-Token | 1.x |
| 数据库 | MySQL | 8.0 |
| 缓存 | Redis | 7.x |
```

> **版本填写规则**：从依赖文件中读取精确版本号；读不到时填 `—`，不得填写猜测版本。

```markdown
---

## ✨ 核心特性

列出项目最重要的能力，使用 `- [x]` checklist 格式，按功能域分组（分组标题用 `####`）：

#### 工程化 / 开发体验
- [x] **TypeScript 全量支持**：接口、Store、组件均有完整类型推导
- [x] **多环境构建**：支持 dev / test / prod 三套环境配置
- [x] **代码规范**：集成 ESLint + StyleLint，Git Hooks 强制校验

#### 业务能力
- [x] **RBAC 权限控制**：角色 → 菜单 → 按钮三级权限
- [x] **Token 无感刷新**：请求拦截器自动续期，用户无感知

每条特性一行，说明**是什么 + 产生什么效果**，不写纯功能标签（如"支持登录"这类无实质信息的条目）。
```

> **checklist 填写规则**：只列出能从代码中**确认存在**的特性；无法确认时省略该条，不得编造。

```markdown
---

## 目录结构

描述关键目录职责，只列有实质内容的目录，不穷举所有文件：

​```
src/
├── controller/   # HTTP 接口层
├── service/      # 业务逻辑层
├── mapper/       # 数据访问层
├── entity/       # 数据库实体类
├── dto/          # 请求 / 响应 DTO
└── config/       # 配置类
​```

---

## 主要模块

| 模块名称 | 路径 | 说明 |
|----------|------|------|
| 用户管理 | src/controller/system/UserController | 用户 CRUD、角色分配 |
| 权限管理 | src/controller/system/RoleController | 角色与权限配置 |
```

> **目录结构写入规则**：
> - **此章节不得省略**。若无法读取目录，保留章节标题并注明 `（待补充）`
> - 只列有实质内容的目录，不穷举所有文件
> - 若某一核心目录（如 `modules/`、`pages/`）下有多个业务子目录，**展开一层**列出子目录及其职责，不要折叠
> - 示例（uni-app 分包结构）：
>
> ````markdown
> ```
> src/
> ├── pages/                # 主包页面
> │   ├── index/            # 首页
> │   └── user/             # 用户中心
> ├── pages-sub/            # 分包页面
> │   ├── order/            # 订单模块
> │   └── health/           # 健康档案模块
> ├── components/           # 公共组件
> ├── store/                # 状态管理（Pinia）
> ├── utils/                # 工具函数
> └── api/                  # 接口层
> ```
> ````
>
> - 取 Controller / 页面目录下的**前 10 个子模块**，按功能分组，不列工具类 / 配置类 / DTO 等非业务模块

```markdown
---

## 依赖服务

| 服务 | 用途 |
|------|------|
| MySQL | 主数据库 |
| Redis | 会话缓存、接口限流 |
| OSS | 文件存储 |

## 快速启动

### 环境准备

| 工具 | 版本要求 | 说明 |
|------|---------|------|
| Node.js | >= 18 | 运行时 |
| pnpm | >= 8 | 包管理器 |
| HBuilderX | 最新稳定版 | 小程序编译（可选） |

> ⚠️ 首次运行前请先复制 `.env.example` 为 `.env.local` 并填写真实配置。

### 安装依赖

​```bash
pnpm install
​```

### 开发模式

​```bash
# H5 开发
pnpm dev:h5

# 微信小程序开发（需 HBuilderX 或 uni-cli）
pnpm dev:mp-weixin
​```

### 生产构建

​```bash
pnpm build:h5
pnpm build:mp-weixin
​```
```

> **启动命令写入规则**：
> - 优先从 `README.md` 中直接引用；若 README 不存在或无启动命令，**保留章节标题并注明"请参考 README.md"**，不要伪造命令
> - 按**阶段分组**：环境准备 → 安装依赖 → 开发模式 → 生产构建，每组用 `###` 子标题隔开
> - 若项目支持多平台（H5 / 小程序 / App），**分行列出各平台命令**并加行内注释说明前提条件（如"需 HBuilderX"）
> - 环境准备表格：列出运行时、包管理器、特殊工具及版本要求；只列能从 `package.json` / `pom.xml` 中确认的版本，无法确认填 `—`
> - 若项目根目录有 `.env.example`，在"安装依赖"前加 `> ⚠️` 块引用提醒复制配置文件

```markdown
---

## 安全注意事项

> ⚠️ 以下配置项在生产环境中**必须修改**，使用默认值存在安全风险：
>
> - **JWT 密钥**（`token.secret`）：默认值为示例字符串，必须替换为 32 位以上随机字符串
> - **数据库密码**：生产环境禁止使用弱密码
> - **Druid 监控密码**（如有）：默认账号密码必须修改或关闭公开访问
>
> 敏感配置请使用环境变量或 Vault 注入，**禁止提交到代码仓库**。
```

> **安全章节写入规则**：
> - 只有在配置文件中**确认存在**默认密钥/密码的情况下才写入此章节
> - 不确定是否有安全风险时，**省略此章节**，不得推测填写
> - 警告内容必须具体说明配置项名称，不写泛泛的"注意安全"

```markdown
---

## 相关文档

| 文档 | 说明 |
|------|------|
| [API 接口](./api.md) | 后端接口清单与权限标识 |
| [环境变量](./env.md) | 各环境配置项说明 |
| [数据库](./database.md) | 核心表结构与字段说明 |
| [Git 规范](./git.md) | 分支策略与 Commit 格式 |
```

> **相关文档写入规则**：只列出 `docs/` 目录下**实际存在**的文档文件；不存在的文件不得列出（避免死链）。

---

## 不同技术栈适配说明

| 项目类型 | 核心特性分组建议 | 技术栈表调整 | 启动命令示例 |
|---------|----------------|------------|------------|
| Spring Boot | 后端能力 / 安全 / 监控 | 保留后端框架 / 持久层 / 认证授权行 | `mvn spring-boot:run` |
| Node.js / NestJS | 后端能力 / 工程化 | 层次改为：运行时 / 框架 / ORM / 认证 | `npm run start:dev` |
| Vue 3 | 工程化 / UI / 业务能力 | 层次改为：框架 / 构建工具 / 路由 / 状态管理 | `npm run dev` |
| uni-app | 工程化 / 多端支持 / 业务能力 | 层次改为：框架 / 构建工具 / 目标平台 | `npm run dev:mp-weixin` |
| Go | 后端能力 / 性能 | 层次改为：语言版本 / 框架 / ORM | `go run main.go` |

根据实际项目类型选择合适的行，无需强制套用 Spring Boot 结构。

## 硬约束（绝对禁止）

- **禁止**覆盖文档中任何已有章节的实质内容
- **禁止**填写无法从文件中确认的版本号或服务地址
- **禁止**伪造或猜测启动命令（无命令时保留章节标题，注明"请参考 README.md"）
- **禁止**在"主要模块"中列出工具类、配置类、DTO 等非业务模块
- **禁止**在未读取配置文件的情况下填写技术栈信息
- **禁止**在无法确认存在安全风险时写入"安全注意事项"章节
- **禁止**在"相关文档"中列出不存在的文件

## 写入前自检

逐项确认后再输出：

- [ ] 未覆盖任何已有章节的实质内容
- [ ] 技术栈版本来自依赖文件，无法确认的已填 `—`
- [ ] 目录结构章节未省略；核心目录的业务子目录已展开一层列出
- [ ] 启动命令来自 README，已按阶段分组；无命令时保留章节标题而非省略
- [ ] 主要模块列表不含工具类 / 配置类 / DTO
- [ ] 核心特性 checklist 每条都有代码可以确认
- [ ] 安全注意事项章节仅在确认有默认密钥/密码时写入
- [ ] 相关文档链接均指向实际存在的文件
- [ ] 无法确认的信息已留空或省略，未被推测填写
