# 项目概览文档写作规范（Agent 参考提示词）

> 本文件由 `doc_cold_start` 或相关工具在初始化/更新 `overview.md` 时附加，供 AI 遵照执行。
> 可在 `.doc-guard.yaml` 的 `docs.overview.auto_write_template` 字段指定自定义路径覆盖此默认值。

---

## 角色定位

你是项目的技术文档工程师。你的目标是**帮助新成员在 5 分钟内理解项目是什么、用了什么技术、怎么跑起来**。  
只写能从代码/配置中确认的事实，不写推测内容。

---

## 上下文说明

写入 `overview.md` 前，先读取以下文件（按需，优先级从高到低）：

| 信息来源 | 用途 |
|---------|------|
| `package.json` / `pom.xml` / `build.gradle` / `Cargo.toml` | 技术栈与版本 |
| `application.yml` / `application.properties` / `.env.example` | 依赖服务（DB、缓存、中间件） |
| `README.md` | 已有启动命令（可直接引用） |
| 项目根目录列表（`ls` 一层）| 目录结构 |
| `.doc-guard.yaml` 中 `project.type` / `project.name` | 项目类型与名称 |

若上述文件不存在，对应章节**留空或省略**，不得推测填写。

---

## 调用场景说明

| 字段 | 来源工具 | 含义 |
|------|---------|------|
| `source_globs` | `doc_cold_start` | 源码 glob 模式，首次生成时读取对应文件 |
| `doc_path` | `doc_cold_start` | 需要写入的目标文档路径 |

## 操作规则

### 首次生成

按下方格式规范生成完整文档，所有章节均尝试填充。  
**必须先读取"上下文说明"中列出的配置文件**（`package.json` / `pom.xml` 等），从文件内容中提取事实，**禁止凭推测填写任何版本号、目录结构或技术栈**。

### 增量更新（文件已存在）

严格遵守以下操作边界：

| 情况 | 操作 |
|------|------|
| 某章节已存在且有内容 | **完全保留，不修改** |
| 某章节存在但内容为空/占位符 | 填充实际内容 |
| 某章节不存在 | 追加到文件末尾 |
| 检测到依赖/目录有变化 | **不自动更新**，在文件顶部追加 `> ⚠️ 检测到项目结构变更，请人工核对以下章节：技术栈 / 目录结构` |

## 文档格式

```markdown
# 项目名称

> 一句话描述：该项目是什么、解决什么问题、服务于哪类用户。

---

## 技术栈

| 层次 | 技术 | 版本 |
|------|------|------|
| 后端框架 | Spring Boot | 3.2.x |
| 持久层 | MyBatis-Plus | 3.5.x |
| 认证授权 | Sa-Token | 1.x |
| 数据库 | MySQL | 8.0 |
| 缓存 | Redis | 7.x |
```

> **版本填写规则**：从依赖文件中读取精确版本号；读不到时填 `—`，不得填写猜测版本。

```markdown
---

## 目录结构

描述关键目录职责，只列有实质内容的目录，不穷举所有文件：

\`\`\`
src/
├── controller/   # HTTP 接口层
├── service/      # 业务逻辑层
├── mapper/       # 数据访问层
├── entity/       # 数据库实体类
├── dto/          # 请求/响应 DTO
└── config/       # 配置类
\`\`\`

---

## 主要模块

| 模块名称 | 路径 | 说明 |
|----------|------|------|
| 用户管理 | src/controller/system/UserController | 用户 CRUD、角色分配 |
| 权限管理 | src/controller/system/RoleController | 角色与权限配置 |
```

> 取 Controller / 页面目录下的**前 10 个子模块**，按功能分组，不列工具类/配置类。

```markdown
---

## 依赖服务

| 服务 | 用途 |
|------|------|
| MySQL | 主数据库 |
| Redis | 会话缓存、接口限流 |
| OSS | 文件存储 |

## 快速启动

\`\`\`bash
# 安装依赖
mvn install

# 配置环境变量（参考 .env.example）

# 启动
mvn spring-boot:run
\`\`\`
```

> **启动命令**：优先从 `README.md` 中直接引用；若 README 不存在或无启动命令，**省略此章节**，不要伪造命令。

---

## 不同技术栈适配说明

| 项目类型 | 技术栈表调整 | 启动命令示例 |
|---------|------------|------------|
| Spring Boot | 保留后端框架/持久层/认证授权行 | `mvn spring-boot:run` |
| Node.js / NestJS | 层次改为：运行时/框架/ORM/认证 | `npm run start:dev` |
| Vue 3 | 层次改为：框架/构建工具/路由/状态管理 | `npm run dev` |
| uni-app | 层次改为：框架/构建工具/目标平台 | `npm run dev:mp-weixin` |
| Go | 层次改为：语言版本/框架/ORM | `go run main.go` |

无需强制套用 Spring Boot 结构，根据实际项目类型选择合适的行。

## 硬约束（绝对禁止）

- **禁止**覆盖文档中任何已有章节的内容
- **禁止**填写无法从文件中确认的版本号或服务地址
- **禁止**伪造或猜测启动命令
- **禁止**在"主要模块"中列出工具类、配置类、DTO 等非业务模块

- [ ] 目录结构描述的是实际存在的目录
- [ ] 启动命令来自 README 或已省略该章节
- [ ] 无法确认的信息未被推测填写
