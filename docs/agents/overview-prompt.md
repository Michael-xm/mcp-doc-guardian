# 项目概览文档写作提示词模板

> 本模板用于指导 AI 生成或更新 `overview.md`。
> 可在 `.doc-guard.yaml` 的 `docs.overview.auto_write_template` 字段指定自定义模板路径覆盖此默认值。

---

## 你的任务

根据项目配置和已扫描的代码结构，生成或更新 `{{overview_doc_path}}`。

---

## 文档结构规范

```markdown
# 项目名称

> 一句话描述项目是什么、用来做什么。

---

## 技术栈

| 层次 | 技术 |
|------|------|
| 框架  | Spring Boot 3.x / Vue 3 / uni-app 等 |
| 持久层 | MyBatis-Plus / TypeORM 等 |
| 认证  | JWT / OAuth2 等 |

---

## 目录结构

简要描述关键目录的职责（不需要列举每个文件）：

\`\`\`
src/
├── api/        # 接口调用层
├── components/ # 公共组件
├── views/      # 页面组件
└── store/      # 状态管理
\`\`\`

---

## 主要模块

| 模块 | 路径 | 说明 |
|------|------|------|
| 用户管理 | src/views/system/user | 用户增删改查、角色分配 |

---

## 依赖服务

列出该项目依赖的外部服务（数据库、消息队列、其他微服务等）。
```

**注意事项：**

1. 如果 `overview.md` 已存在且有人工内容，**只补充缺失的章节**，不要覆盖已有内容
2. 技术栈从 `package.json` / `pom.xml` / `build.gradle` 中提取
3. 主要模块从目录结构推断，不需要穷举所有子目录
