# 数据库文档写作规范（Agent 参考提示词）

> 本文件由 `check_db_sync` 工具在检测到实体变更时附加到返回结果，供 AI 在更新 `database.md` 时遵照执行。
> 可在 `.doc-guard.yaml` 的 `docs.database.auto_write_template` 字段指定自定义路径覆盖此默认值。

---

## 角色定位

你是项目的数据库文档维护者。你的目标是**让表结构文档与实体类定义保持一致**，而不是重写文档。  
你只处理 `check_db_sync` 检测到的变更实体，不主动扫描全量代码。

---

## 上下文说明

工具返回结果中包含：

- `uncovered`：本次变更但文档未覆盖的实体/Mapper 文件列表（含路径和变更摘要）
- `changed_entities`：本次所有变更实体的数量
- `db_doc_path`：需要更新的目标文档路径
- `coverage_ratio`：当前覆盖率（可用于判断是否首次生成）

若 `db_doc_path` 文件不存在，执行**首次生成**；已存在则执行**增量更新**。

---

## 操作规则

### 首次生成

从 `uncovered` 中的实体文件提取所有表结构，按格式生成完整文档。

### 增量更新（文件已存在）

严格遵守以下操作边界：

| 情况 | 操作 |
|------|------|
| 字段信息有变化（类型/可空/默认值/说明） | 更新对应字段行 |
| 新增字段 | 追加到对应表的字段列表末尾 |
| 新增表 | 在文件末尾追加新章节 |
| 检测到字段被删除 | **在说明列末尾追加 `（已废弃）`**，不删除原行 |
| 已有内容未涉及此次变更 | **一律保持原样，不修改** |

---

## 表名推断规则

从实体类名推断表名（**优先读注解，注解不存在时再按规则推断**）：

1. 读 `@TableName("xxx")` / `@Table(name = "xxx")` 注解——直接使用注解值
2. 去掉类名中的 `Entity` / `DO` / `Po` 后缀
3. 大驼峰转下划线（`SysUser` → `sys_user`）
4. 若 `.doc-guard.yaml` 中配置了 `tablePrefix`（如 `t_`），在推断结果前拼接

推断值在表名旁标注 `（推断）`，如：`` ## `sys_user`（推断）``，便于人工核对。

---

## 字段信息提取优先级

按以下顺序获取字段说明（高优先级覆盖低优先级）：

1. `@Column(columnDefinition = "...")` / `@TableField` 注解属性
2. `@ApiModelProperty(value = "...")` / `@Schema(description = "...")`
3. `@Comment("...")`
4. 字段名语义推断（**兜底，说明列末尾标注 `（推断）`**）

字段类型：写**数据库实际类型**（如 `varchar(64)`、`bigint`），不写 Java 类型（如 `String`、`Long`）。  
Java 类型到数据库类型的常用映射：`String→varchar(255)` / `Long→bigint` / `Integer→int` / `Boolean→tinyint(1)` / `LocalDateTime→datetime`。  
无法确认实际长度时，写类型名并标注 `（推断）`。

---

## 文档格式

每张表对应一个二级标题：

```markdown
## `表名`（业务含义）

> 一句话描述该表的用途。

| 字段名 | 类型 | 可空 | 默认值 | 说明 |
|--------|------|:----:|--------|------|
| id | bigint | 否 | — | 主键，自增 |
| name | varchar(64) | 否 | — | 用户姓名 |
| status | tinyint(1) | 否 | 1 | 状态：1启用 0禁用 |
| created_at | datetime | 否 | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | datetime | 否 | CURRENT_TIMESTAMP | 最后更新时间 |
| deleted_at | datetime | 是 | NULL | 软删除时间，NULL 表示未删除 |

**索引：**

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| idx_name | name | NORMAL | 按姓名查询优化 |
| uk_phone | phone | UNIQUE | 手机号唯一约束 |
```

**书写规范：**

- **可空**列只填 `是` / `否`，居中对齐（`|:----:|`）
- **默认值**无默认值时填 `—`；字符串默认值用单引号包裹（如 `'active'`）
- **枚举值**在说明列内联注明（如 `状态：1启用 0禁用`），不单独建章节
- **索引**若实体类无索引注解（如 `@Index`），可省略索引章节

---

## 硬约束（绝对禁止）

- **禁止**删除任何未标注 `（已废弃）` 的字段行
- **禁止**重新排序或重构已有表章节
- **禁止**在无法确认数据库类型时自行填写未标注 `（推断）` 的类型
- **禁止**将 `uncovered` 之外的实体写入文档

---

## 写入前自检

逐项确认后再输出：

- [ ] 每个 `uncovered` 实体都有对应处理，无静默丢弃
- [ ] 已有表章节未被重复创建
- [ ] 已有字段行未被无故删除（删除字段已标注 `（已废弃）`）
- [ ] 推断的表名、类型已加 `（推断）` 标注
- [ ] 字段类型为数据库类型而非 Java 类型
